# AICEcho 3.0.3

本次更新改善 Shizuku 方式的刷卡稳定性，不需要重新添加卡片或重新配置已正常使用的卡片。

## 更新内容

- **减少识别成其他卡片的情况**：改善刚开始模拟或刷卡成功后仍贴着读卡器时，偶发识别成小米互联等卡片、无法继续刷卡的问题。
- **模拟期间保持刷卡监听**：Android 15 及以上的 Shizuku 模拟页优先使用当前卡片的 NFC-F 监听；退出模拟页后恢复默认监听。不支持此接口的设备和 Root 模块方式保留原流程。
- **准备提示更清楚**：开始模拟时提示先移开读卡器，等页面确认已启用后再贴近刷卡。

## 下载与更新

下载下方的 **`AICEcho-3.0.3-release.apk`**，可直接覆盖同签名的 AICEcho 3.0.2 或本次监听修复测试包，保留已有卡片资料。更新前建议导出一份本地备份。

使用 Shizuku 不需要安装 `aicecho-pmm-ksu-v3.zip`；已有 Root 的用户按原设置使用即可，本次更新没有改变 Root 模拟流程。

首次使用和手机条件见 [使用说明](https://github.com/UmiSlat/AICEcho#第一次使用)。
