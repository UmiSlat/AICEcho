# AICEcho 3.0.2

AICEcho 首个正式版本发布。读取并保存自己的实体卡资料后，可以在支持的手机上模拟刷卡。

## 主要功能

- **读取和管理卡片**：保存多张卡片，按名称选择要使用的卡片。
- **手机刷卡**：支持 Shizuku 和 Root 模块两种方式；Shizuku 配好同一张卡后，日常使用不必保持它运行。
- **更清楚的操作流程**：首页提示配置或开始模拟，不常用的参数收进高级模式。
- **本地备份**：导入和导出卡片资料，方便保留备份或换手机。
- **全新名称与图标**：应用名称统一为 AICEcho。

## 下载与使用

安装下方的 **`AICEcho-3.0.2-release.apk`**，按[使用说明](https://github.com/UmiSlat/AICEcho#第一次使用)添加卡片并完成手机配置。

使用 Shizuku 需要 Android 14 及以上和 NFC-F 卡片模拟支持。已有 Root 的用户可按[Root 教程](https://github.com/UmiSlat/AICEcho/blob/main/docs/ROOT_SETUP.md)设置；`aicecho-pmm-ksu-v3.zip` 是可选补丁，使用 Shizuku 不需要安装它。

新包的实机适配仍在验证中，已测试范围和设备条件见[README](https://github.com/UmiSlat/AICEcho#使用范围与注意事项)。
