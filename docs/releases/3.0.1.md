# AimeSimulator 3.0.1

这是 AimeSimulator 的首个正式版本。此前的 `v3.0.0` 保留为预发布，原标签和安装包不变。

## 主要功能

- 读取、保存、编辑和管理多张卡片，通过本地备份导入或导出资料。
- Shizuku 方式在手机内完成卡片配置；已经配置好的同一张卡，日常模拟不必保持 Shizuku 运行。
- 已授权的 Shizuku 自动连接，首页按状态显示“配置并使用”“开始模拟”或“继续完成配置”。
- 配置流程收拢为四阶段向导，详细参数、诊断与回滚工具移入高级模式。
- 模拟页增加状态检查、NFC 开关恢复和“重新连接”，区分等待刷卡、收到请求及未生成回应。
- 保留 Root 模块方式的原有前台激活流程。

## 下载与开始使用

下载资源中的 `AimeSimulator-3.0.1-release.apk`。安装后读取实体卡或导入备份，在卡片页选择要用的卡片，再按主按钮完成配置或开始模拟。

APK 面向 ARM64，最低 Android 10。Shizuku 配置方式需要 Android 14 及以上、支持 NFC-F 卡片模拟，并通过调试方式启动 Shizuku。Root 模块方式需要可用的 LSPosed。具体条件与步骤见[使用说明](https://github.com/UmiSlat/AimeSimulator#第一次使用)。

`aimesim-pmm-ksu-v3.zip` 是可选的 KernelSU 兼容补丁，不是 APK，也不是 Shizuku 方式的必需品；适用范围及安装方法见[Root 教程](https://github.com/UmiSlat/AimeSimulator/blob/main/docs/ROOT_SETUP.md)。

## 更新与兼容性

更新前建议导出卡片备份。同一正式签名的旧包可覆盖升级；开发 debug 包可能使用不同证书，不要为安装新版直接卸载而丢失资料。

目前实机配置与读卡证据来自 Xiaomi 15 Pro / Android 16 / HyperOS；其他设备和机台的适配仍以实际结果为准。新会话恢复与界面整理已完成本地回归，具体证据和后续实机项目见[验收记录](https://github.com/UmiSlat/AimeSimulator/blob/main/docs/3.0_ACCEPTANCE.md)。

每个下载文件附有 `.sha256` 校验文件。资料、默认钱包与原卡参数不会因为版本号升级而自动改变。
