# AimeSimulator 3.0.1

首个正式版本发布。你可以读取和保存自己的卡片资料，通过 Shizuku 或 Root 模块在手机上模拟卡片。

## 本次更新

- **Shizuku 自动连接**：已启动并授权后，再次打开应用不用手动连接。
- **卡片使用流程更清楚**：添加、配置和开始模拟的入口重新整理，首页会提示下一步该做什么。
- **默认界面更简洁**：不常用的参数和诊断工具收进高级模式，日常使用不需要逐项设置。
- **增加“重新连接”**：模拟没有反应时，可以先在模拟页尝试重新连接；关闭再打开 NFC 后也会尝试恢复模拟。
- **Shizuku 日常使用更省事**：同一张卡配置完成后，开始模拟不必保持 Shizuku 运行。换卡时再重新配置即可。

## 下载与使用

安装下方的 **`AimeSimulator-3.0.1-release.apk`**，添加卡片后按首页提示操作。首次使用请看[使用说明](https://github.com/UmiSlat/AICEcho#第一次使用)，应用内也可检查设备是否满足条件。

Shizuku 方式需要 Android 14 及以上和 NFC-F 模拟支持，目前已在 Xiaomi 15 Pro 上验证，其他机型仍待验证。Root 模块方式的设置见[Root 教程](https://github.com/UmiSlat/AICEcho/blob/main/docs/ROOT_SETUP.md)；下方的 `aimesim-pmm-ksu-v3.zip` 是可选补丁，使用 Shizuku 不需要安装它。

更新前建议导出卡片备份。如果旧测试版因签名不同无法覆盖安装，请先备份，不要直接卸载。
