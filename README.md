# AICEcho

AICEcho 是一款 Android 卡片管理与模拟应用，主要用于 Amusement IC / Aime 类型的卡片。读取并保存自己的实体卡资料后，可以在支持的手机上刷卡，也可以管理多张卡片、导入和导出本地备份。

首次使用：**添加卡片 → 配置到手机 → 开始模拟**。同一张卡配置好以后，日常只需选卡并开始模拟，不用每次重新配置。

## 我的手机能用吗？

| 你想做什么 | 需要什么 |
| --- | --- |
| 保存、编辑和备份卡片 | Android 10 及以上；不需要 Root 或 NFC |
| 读取实体卡 | Android 10 及以上，手机有 NFC，且能读取这张卡 |
| 用 Shizuku 在手机上刷卡 | Android 14 及以上，支持 NFC-F 卡片模拟；使用手机主空间，没有额外用户、应用分身或工作资料；安装 Shizuku 13 或更新版本，并通过无线调试或电脑启动 |
| 已有 Root，用模块刷卡 | Android 10 及以上，支持 NFC-F 卡片模拟，并有可用的 LSPosed；按[Root 教程](docs/ROOT_SETUP.md)设置 |

当前安装包为 ARM64 版本，最低支持 Android 10。

**有 NFC 不等于能模拟卡片。** 安装后打开“状态 → 设备兼容性”，查看“卡片模拟支持”。不支持模拟的手机仍可管理和备份卡片，有 NFC 的手机还可尝试读取实体卡。已测试范围见下方[使用范围与注意事项](#使用范围与注意事项)。

## 下载与安装

**[下载 AICEcho 3.0.2 正式版](https://github.com/UmiSlat/AICEcho/releases/tag/v3.0.2)**

打开下载页，在 **Assets** 中下载 **`AICEcho-3.0.2-release.apk`**，传到手机安装即可，不需要下载源码或自行编译。

同页的 `aicecho-pmm-ksu-v3.zip` 是可选的 Root 兼容补丁，不是应用安装包。使用 Shizuku 时，只需安装 APK，不需要安装这个补丁。

日常使用优先选择正式版。想提前体验开发中的更新，可在 [Actions](https://github.com/UmiSlat/AICEcho/actions/workflows/android-ci.yml) 选择成功的 `main` 构建，下载 `AICEcho-release-…` 产物并解压安装；测试版下载需要登录 GitHub。

## 第一次使用

下面以 **Shizuku 方式**为例。它用于帮助应用完成手机配置，不要求给 AICEcho Root 权限。已经使用 Root 模块的用户可直接按[Root 教程](docs/ROOT_SETUP.md)操作，不必再走这套配置流程。

### 1. 检查手机

开启手机 NFC，打开“状态 → 设备兼容性”，确认“卡片模拟支持”。还没有添加卡片时，其他检查项可能提示先选卡，按下一步添加即可。

### 2. 读取并保存卡片

1. 在“卡片”页点“添加卡片 → 读取卡片”。
2. 把实体卡贴近手机 NFC 天线，保持不动，等待读取结果。
3. 点“使用此数据”，给它起一个容易认出的名字，保存并选中。

已有 **AICEcho 导出的备份**时，可改用“添加卡片 → 导入备份”。读取结果会自动填入卡片资料，通常不需要改动原始参数。

### 3. 配置手机刷卡

1. 从[官网下载 Shizuku](https://shizuku.rikka.app/zh-hans/download/)，按[官方教程](https://shizuku.rikka.app/zh-hans/guide/setup/)通过**无线调试或电脑**启动，不要选择“通过 Root 启动”。
2. 在 AICEcho 的“状态 → 模拟方式”选择“Shizuku”，再回到“卡片”页，点“配置并使用”。首次使用时允许 Shizuku 授权；之后只要 Shizuku 已启动，应用会自动连接。
3. 跟随页面完成检查。出现“应用配置”时确认操作，在系统恢复页点**“恢复我的数据”**，密码留空。部分手机还会显示备份确认页，同样不要设置密码。
4. 点**“加载配置”**，确认重启 NFC，等待核对完成，再点“开始模拟”。

配置页只显示当前需要的操作。中途退出后，可从首页点“继续完成配置”；普通使用不需要开启高级模式。

### 4. 开始刷卡

选中要用的卡，点“开始模拟”，保持刷卡页打开、手机解锁，将手机 NFC 天线贴近读卡器。刷卡结束后返回上一页，模拟就会停止。

同一张卡配置好后，日常刷卡**不必保持 Shizuku 运行**。换卡或修改卡片电子标识后，按首页提示重新配置；仅选中或保存卡片不会自动完成配置。

## 常见问题

### 显示正在模拟，读卡器却没有反应？

先调整手机位置，尝试横放、贴紧读卡器或取下厚手机壳。确认位置没问题后，在 Shizuku 模拟页点“重新连接”，或返回卡片页再开始。

仍无响应时，可关闭再打开 NFC 后重试，必要时重启手机。先尝试这些操作，不必一上来就重新配置卡片。反馈问题时附上手机型号、Android 版本、应用版本、模拟方式和页面提示。

### 已保存、已选中和已配置，有什么区别？

“已保存”是资料在应用里，“已选中”是当前要用的卡，“已配置到手机”才表示手机已登记这张卡。Shizuku 方式下，首页显示“配置并使用”时先配置，显示“开始模拟”时直接开始。

### IDm 和 Access Code 需要自己填写吗？

读取原卡后，**IDm**（卡片电子标识）会自动填入。**Access Code** 是卡面印刷的 20 位号码，只用于记录和显示，可以留空。保留读到的原始资料即可，不需要为了模拟而修改参数。

只有卡面号码不能还原完整卡片资料，也不能算出 IDm。建议在实体卡还在手里时读取并备份。

### 提示需要配置，或者系统拒绝卡片标识怎么办？

先检查“状态 → 模拟方式”。Shizuku 方式需完成当前卡片的配置；Root 方式需按[模块教程](docs/ROOT_SETUP.md)启用模块并重启手机。

配置失败时，按页面提示处理，并在“设备兼容性”查看原因，不要改成随机卡号来绕过提示。

### 要不要把它设为默认 NFC 应用？

不是所有手机都需要，先保持原设置。应用提示确实需要切换时，再到“状态”页操作；用完可以点“恢复手机钱包”，在系统页面重新选择原钱包。

### 高级模式是做什么的？

它会显示完整参数、诊断信息和手动配置工具，日常刷卡不用开启。**开启开关本身**不会修改卡片；里面的配置、恢复等操作需要另外确认。完整卡片资料也可从“卡片 → 详情”查看。

## 备份卡片

到“设置 → 卡片数据”点“导出”，得到包含全部已保存卡片资料的 JSON 文件。换手机或重新安装 AICEcho 时，在“添加卡片 → 导入备份”选择该文件；导入前可以预览，并选择合并或替换。

导入的是卡片资料，不是手机刷卡配置。导入并选卡后，仍需按首页提示配置新手机。资料只保存在本机，没有在线账号或自动云同步。

## 使用范围与注意事项

此前版本在 Xiaomi 15 Pro / Android 16 / HyperOS 上验证过卡片配置、切换、恢复和 HINATA 读卡。**更名后的 AICEcho 新包尚未完成实机复验**，其他机型、完全未 Root 的设备与游戏账号识别也仍待验证。已验证范围与待测项目见[验收记录](docs/3.0_ACCEPTANCE.md)。

- 当前模拟面向 FeliCa 类型的卡片，不是通用门禁卡模拟器。老式 MIFARE Aime 仅有读取卡号的实现，未做旧卡实测；不支持模拟这种旧卡，也不提供写入实体白卡的功能。
- 更新前先导出 AICEcho 备份。同签名且版本码不低于当前版本的安装包可覆盖更新；若提示签名不一致，先保留资料，不要直接卸载。
- 默认 NFC 应用切换可能影响原钱包的碰一碰支付；用完可在“状态 → 恢复手机钱包”恢复。配置时重启 NFC 会短暂中断刷卡，操作期间请移开读卡器。
- 备份是明文，完整卡片详情和诊断日志也可能包含卡号，请私密保存。
- 仅使用你拥有或获准使用的卡片和设备。本项目是非官方工具，与 Aime 等相关厂商或运营方无隶属或背书关系，相关名称和标识属于各自权利人。
- 项目自有代码目前尚未添加项目级开源许可证；第三方组件遵循各自许可证。来源和权利说明见[实现来源](docs/PROVENANCE.md)与[第三方组件](THIRD_PARTY_NOTICES.md)。
